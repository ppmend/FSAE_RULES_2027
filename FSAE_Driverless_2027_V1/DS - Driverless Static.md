# DS - DRIVERLESS STATIC

## DS.1 FORMULA SAE ELECTRIC

### DS.1.1 Vehicle Configuration

The Driverless System must stay on the vehicle for the Formula SAE Electric Design and Cost Events

### DS.1.2 Driverless Component Summary

**DI.1.2.1** The team must provide an itemized list of the components that are part of the Driverless System and serve no other function or purpose on the vehicle

If in question, the team must prove that a component meets this requirement

The list will show what should not be judged during Formula SAE Cost Event, and may be a reference for the Formula SAE Design Event

**DI.1.2.2** Refer the Event Website for submission details GR.4.3

### DS.1.3 Formula SAE Electric Design Event

The team Formula SAE Electric Design Event score will not receive additional points or be penalized for the Driverless System and components

### DS.1.4 Formula SAE Electric Cost Event

**DS.1.4.1** The Driverless System and components will not be judged

**DS.1.4.2** The Vehicle Cost will not include the Driverless System or components

**DS.1.4.3** The team Formula SAE Electric Cost Event score will not receive additional points or be penalized for the Driverless System and components

## DS.2 DRIVERLESS DESIGN EVENT

### DS.2.1 Objective

**DS.2.1.1** Driverless Design will evaluate the team understanding and execution of the sensors, actuators, control logic, processing and software for operation in Driverless Mode

**DS.2.1.2** Driverless Design will follow Formula SAE Rules for the Design Event S.4 unless specific information is published in the Event Handbook or on the Event Website GR.4.3

### DS.2.2 Driverless System Summary

The Driverless System Summary is included in the Design Briefing template S.4.3

### DS.2.3 Driverless Design Judging

**DS.2.3.1** The Driverless System and components will be:

- a. Judged during the Formula SAE Design Event or separately DS.2.1.2
- b. Scored separately from the Formula SAE Design Event

**DS.2.3.2** Driverless Design Score Sheets are available at the Event Website
